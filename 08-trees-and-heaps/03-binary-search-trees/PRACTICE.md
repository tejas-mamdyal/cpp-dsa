# Independent practice

Use C++17 and the corresponding worked lesson domains, including small exponential bounds. For each task provide a contract, baseline, hand trace, proof, complexity and meaningful normal/boundary/counterexample checks. Attempt independently before opening hints.

## 1. Task 1

Build an ancestor violation whose immediate child inequalities appear valid.

## 2. Task 2

Insert one key three times and verify only one node exists.

## 3. Task 3

Validate a BST containing INT_MIN and INT_MAX.

## 4. Task 4

Delete a leaf, one-child node and two-child root; compare after each step with std:: set.

## 5. Task 5

Compare floor, ceil, predecessor and successor for present and absent queries.

## 6. Task 6

Return all ascending and descending ranks; test 0 and n+1.

## 7. Task 7

Compare inclusive range results to filtering inorder values.

## 8. Task 8

Reject an LCA query where one key is absent despite a plausible split.

## 9. Task 9

Rebalance an increasing chain; compare keys and height while retaining original.

## 10. Task 10

Explain why a singleton 5 cannot provide sum 10.

## 11. Task 11

Instrument iterator pushes/pops across a complete traversal.

## 12. Task 12

Merge overlapping BST key sets and verify sorted distinct union.
