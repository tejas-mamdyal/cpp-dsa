# Independent practice

Use C++17 and the corresponding worked lesson domains, including small exponential bounds. For each task provide a contract, baseline, hand trace, proof, complexity and meaningful normal/boundary/counterexample checks. Attempt independently before opening hints.

## 1. Task 1

Return optional parent indices and explain why root has none.

## 2. Task 2

Give a valid heap that is neither ascending nor descending.

## 3. Task 3

Compare 200 interleaved heap operations to a multiset.

## 4. Task 4

Build by repeated push and bottom-up repair; compare popped sequences.

## 5. Task 5

Show why heap-sort repair must exclude the finalized suffix.

## 6. Task 6

Specify a secondary name order for equal-priority tasks.

## 7. Task 7

Find kth largest in[5,5,2] for k 2 and contrast distinct ranking.

## 8. Task 8

Enumerate all pair merges for at most 6 ropes and compare minimum cost to greedy.

## 9. Task 9

Merge sorted rows with empties and repeated values.

## 10. Task 10

Audit owned-list merge: all source heads null, every node visited once.

## 11. Task 11

Compare each running median to a sorted prefix, including negatives.

## 12. Task 12

Refute small-k frontier sorting on arbitrary unconstrained data.
