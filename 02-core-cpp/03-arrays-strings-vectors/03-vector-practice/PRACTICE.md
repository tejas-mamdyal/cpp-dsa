# Independent practice: Vectors and standard array questions

Write each solution from a blank file. Use C++17 and state input constraints,
return/absence policy, cost and at least one empty/invalid/boundary case.
Small exercise integers have absolute value <=1000000 unless stated otherwise.

## 1. Third distinct maximum

Return an optional third distinct maximum.

Example: 2,5,5,9,7 ->5.

## 2. Stable negative partition

Copy negatives first then nonnegatives, preserving each group order.

Example: 3,-1,0,-2 ->-1,-2,3,0.

## 3. Rotate right

Handle k larger than n and n=0.

Example: 1,2,3; k4 ->3,1,2.

## 4. Is sorted

Check nondecreasing order.

Example: 1,1,3 ->true;2,1 ->false.

## 5. Merge with empty side

Generalize the merge exercise for either empty input and duplicates.

Example: empty +1,1 ->1,1.

## 6. Erase by value

Remove every target while retaining other values in order.

Example: 1,2,1,3 target1 ->2,3.

## 7. Flatten ragged rows

Flatten rows of unequal length.

Example: [1,2],[],[3] ->1,2,3.

## 8. Reserve diagnosis

Explain why reserve10 then v[0]=7 is wrong and repair it.

Example: resize1 then v[0]=7 succeeds.
