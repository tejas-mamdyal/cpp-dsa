# Independent practice

Use C++17 and the corresponding worked lesson domains, including small exponential bounds. For each task provide a contract, baseline, hand trace, proof, complexity and meaningful normal/boundary/counterexample checks. Attempt independently before opening hints.

## 1. Task 1

Return unique subsets of[2,1,2,1] and compare to a deduplicated mask reference.

## 2. Task 2

Return unique permutations of[2,2,1] and verify every used flag clears.

## 3. Task 3

Compare swapping and used-flag permutations for distinct inputs through length 6.

## 4. Task 4

Return the third lexicographic unique permutation of[1,1,2,2].

## 5. Task 5

Return unlimited-reuse target 8 combinations from 2,3,5.

## 6. Task 6

Return single-use target 4 combinations from[1,1,2,2,3].

## 7. Task 7

Choose 4 distinct digits 1..9 totaling 20.

## 8. Task 8

Implement iterative subsets and refute extending a growing out.size().

## 9. Task 9

Verify reflected Gray-code adjacency including last-to-first for n>=1.

## 10. Task 10

Generate all case variants ofa 0B 9, including exact multiplicities.

## 11. Task 11

Return nondecreasing subsequences of[3,1,2,2] without sorting input.

## 12. Task 12

Compare factorial-block ranks to full enumeration for every valid rank through n 6.
