# Independent practice

Use C++17 and the corresponding worked lesson domains, including small exponential bounds. For each task provide a contract, baseline, hand trace, proof, complexity and meaningful normal/boundary/counterexample checks. Attempt independently before opening hints.

## 1. Task 1

Return and independently validate every 4-queen board.

## 2. Task 2

Count queen boards with specified forbidden cells.

## 3. Task 3

Reject a filled invalid Sudoku and preserve it unchanged.

## 4. Task 4

Construct an unsatisfiable valid-clue 4x 4 puzzle and verify failure restores all blanks.

## 5. Task 5

Compare first-blank and MRV node counts on one Sudoku.

## 6. Task 6

Validate a coloring by scanning all matrix edges.

## 7. Task 7

Count labeled colorings of a three-vertex path with 2 and 3 colors.

## 8. Task 8

Validate a supplied knight tour by bounds, uniqueness and move deltas.

## 9. Task 9

Explain why a Hamiltonian route on a chain need not be a cycle.

## 10. Task 10

SolveI+BB=ILL and test leading-zero rejection.

## 11. Task 11

Return selected indices for tiny indivisible knapsack and independently check capacity.

## 12. Task 12

Compare queens to complete permutation enumeration for n 0..7.
