# Coverage and scope

This is a growing course, not a claim that every algorithm or C++ feature has
already been explained exhaustively. The learning route and coverage below make
missing depth explicit. Each implemented algorithm has its own runnable source;
exercises extend the idea and are not claimed as implemented solutions.

## Implemented course areas

- Programming model, types, input/output, control flow, functions and scope.
- Arrays, strings, vectors, pointers, references, dynamic memory and classes.
- Templates, exceptions, RAII, ownership, moves and virtual interfaces.
- File streams, header guards and an introduction to multiple-file program organization.
- STL containers, iterators, algorithms and comparators.
- Complexity, hashing, two pointers, windows, prefix sums and Kadane.
- Binary search, elementary/merge sorting, recursion and basic structures.
- Lists, stacks, queues, trees, BSTs, heaps and priority queues.
- Graph representation/traversal, components, cycles, bipartiteness, topological sort.
- Dijkstra, BFS paths, DSU and Kruskal.
- GCD, sieve, modular power, bit operations and subset masks.
- Backtracking subsets and N-queens; greedy scheduling and answer search.
- DP: linear, knapsack, coin change, LCS, LIS, intervals, subset tours, grids,
  tree independent sets and digit constraints.
- Monotonic stack/deque, Fenwick tree, lazy segment tree and sparse table.
- Trie, prefix function/KMP and Z function.
- Quicksort/counting sort, prime factorization, modular inverses and combinations.
- Unique permutations, interval merging, weighted scheduling, edit distance,
  Manacher palindrome radii, Prim, articulation points and convex hull.
- Bellman-Ford, Floyd-Warshall, 0-1 BFS, SCCs, bridges, binary-lifting LCA and flow.

## Extension track needing dedicated implementations or deeper treatment

- C++: larger multiple-file projects, build systems, operator overloading,
  copy/move special members, template specialization, concepts, concurrency and networking.
  C++17 DSA does not require the entire modern C++ language or systems programming.
- Sorting: selection, radix sort and selection by quickselect.
- Math: CRT and matrix exponentiation.
- Search: rotated arrays, exponential search, meet in the middle and ternary search.
- Backtracking: combination sum, graph coloring and Sudoku implementations.
- DP: stock states, rerooting, profile DP,
  convex-hull optimization and divide-and-conquer optimization.
- Structures: balanced BST internals, persistent trees, heavy-light decomposition,
  order statistics, square-root decomposition and Mo's algorithm.
- Strings: rolling hashes/collision analysis, suffix arrays/LCP,
  suffix automata and Aho-Corasick.
- Graphs: Euler tours, Eulerian paths, matching,
  Dinic, min-cost flow, 2-SAT and offline dynamic connectivity.
- Geometry: segment intersection, closest pair and further numerical robustness.

Use the exercise bank for intermediate extensions. A topic listed here is not
silently treated as completed. Older examples also vary in comment depth; use
