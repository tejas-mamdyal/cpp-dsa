# Independent practice

Each teaching unit contains a PRACTICE.md with a separate HINTS.md,debugging lab and scored checkpoint. Follow [the learning order](../LEARNING_ORDER.md) so exercises build on completed prerequisites.

The [placement library](placement/README.md) supplies60 problem statements,30 timed sets of2 problems,12 mock packs and6 cumulative assessments. Begin with the statement and a baseline;open the separated answer key only after an independent attempt. Record proof,costs,counterexamples and retries in [the notebook](../13-placement-preparation/INTERVIEW_NOTEBOOK.md).
