# Comparators, lambdas and captures

Continue in [capture/comparator practice](../10-lambda-practice/README.md).

Prerequisites: classes, references, auto, pairs and half-open iterator ranges.
A comparator is a callable whose true result says the first argument precedes the
second. It must be strict: comparing an object with itself returns false.

1. [Basic lambdas and ordering](01_lambdas.cpp)
2. [Function objects, captures and typed wrappers](02_function_objects_and_captures.cpp)

closures have the syntax they need. Recursion itself is taught in chapter04 before
