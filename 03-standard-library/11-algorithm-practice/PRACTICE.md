# Independent practice: Algorithms numeric utilities and applications

Write each solution from a blank file. Use C++17 and state input constraints,
return/absence policy, cost and at least one empty/invalid/boundary case.
Small exercise integers have absolute value <=1000000 unless stated otherwise.

## 1. Equal range

Count all occurrences of a target in a sorted vector.

Example: 1,2,2,2,4 target2 ->3.

## 2. Filter marks

Remove marks below40 using erase-remove.

Example: 20,50,39,80 ->50,80.

## 3. Sorted dedup

Remove all duplicate values in unsorted input.

Example: 3,1,3,2 ->1,2,3.

## 4. Long sum

Sum100000 values each1000000 safely.

Example: 100000000000.

## 5. Stable ties

Sort score/name records while retaining original order for equal scores.

Example: equal-score names remain in arrival order.

## 6. Kth rank

Select the median rank without sorting every element.

Example: 9,1,5 ->5.

## 7. Permutation count

Count distinct permutations of1,1,2,2.

Example: 6.

## 8. Heap updates

Append a value, restore the heap, remove the maximum.

Example: 3,1 plus9 ->maximum9.
