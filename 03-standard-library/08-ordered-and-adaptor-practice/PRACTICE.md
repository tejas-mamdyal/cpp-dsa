# Independent practice: Ordered containers and adaptors

Write each solution from a blank file. Use C++17 and state input constraints,
return/absence policy, cost and at least one empty/invalid/boundary case.
Small exercise integers have absolute value <=1000000 unless stated otherwise.

## 1. Sorted unique IDs

Deduplicate and print IDs in order.

Example: 3,1,3,2 ->1,2,3.

## 2. Erase one duplicate

Remove one2 from2,2,3.

Example: one2 remains.

## 3. Range count

Count ordered values in inclusive[low,high].

Example: 1,2,2,4 with2..3 ->2.

## 4. Phone index

Store one phone per name without inserting during lookup.

Example: missing name leaves size unchanged.

## 5. Balanced angle brackets

Extend the bracket validator to include < and >.

Example: <[]> ->true; <] ->false.

## 6. Service simulation

Interleave job arrivals and one-at-a-time service.

Example: add1,add2,serve,add3 ->pending2,3.

## 7. Kth largest

Return the kth-largest value counting duplicates, or absence if k invalid.

Example: 3,9,5,k2 ->5.

## 8. Priority tie break

Order jobs by priority, then earlier ID.

Example: priority5 IDs1,2 serve1 first.
