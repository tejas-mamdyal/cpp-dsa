# Expressions and formulas

Start with [the dedicated operator unit](00-operators/README.md), then use the
formula programs below as applications. Revisit [bitwise applications](00-operators/applications/README.md) after loops.

Prerequisites: Units 01–02: streams, types and conversions.

Read [the unit notes](NOTES.md), then work through the lessons in order. The first
eight form the core route; later programs add reinforcement. Work through all of
them if a concept is still uncertain. Every source has a contract, explanation,
trace, cost, pitfalls and two follow-up tasks.

- [Four arithmetic operations](01_arithmetic.cpp) — core
- [Parentheses change the calculation](02_precedence.cpp) — core
- [Quotient and remainder partition a count](03_remainder.cpp) — core
- [Decompose a duration](04_seconds.cpp) — core
- [Real-valued unit conversion](05_celsius.cpp) — core
- [Average without integer truncation](06_average.cpp) — core
- [Translate a percentage formula](07_interest.cpp) — core
- [Extract the final decimal digit](08_last_digit.cpp) — core
- [Compound assignment updates a balance](09_compound.cpp) — reinforcement
- [Comparisons produce truth values](10_comparisons.cpp) — reinforcement
- [Combine a lower and upper bound](11_logical_range.cpp) — reinforcement
- [Guard a dangerous expression](12_short_circuit.cpp) — reinforcement

Attempt [independent practice](PRACTICE.md) before opening [hints](HINTS.md).
Finish [the checkpoint](CHECKPOINT.md) before advancing. Revisit a weak concept
with a smaller input rather than memorizing a complete solution.
