# Bitwise application practice

Solve from a blank file; state constraints and add a boundary test.

## 1. Three pairs and one singleton

Apply XOR without storing the input array.

Expected example: 8,3,8,4,3,4,9 ->9.

## 2. Broken multiplicity

Explain why the singleton method is invalid when values occur three times.

Expected example: 2,2,2,7 is not the paired contract.

## 3. Parity of set bits

Return whether the set-bit count is odd.

Expected example: 7 ->true;3 ->false.

## 4. Hamming distance

Count differing positions of two nonnegative integers.

Expected example: 10,12 ->2.

## 5. Mask test

Check whether all bits in a mask are present.

Expected example: flags14,mask6 ->true.

## 6. Clear low bit

Apply x&(x-1) once and explain the borrow pattern.

Expected example: 12 ->8.

## 7. Power-of-two boundary

Test0,1,2,3,1024 and a negative number.

Expected example: only1,2,1024 true.

## 8. Low four bits

Complement only the lowest four bits of a value0..15.

Expected example: 12 ->3.
