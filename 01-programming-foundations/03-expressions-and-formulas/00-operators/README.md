# Operators: names, meaning and when to learn them

Read the 14 scalar examples in this folder after values/types and before formula
applications. Each is a complete program. Read the four [applications](applications/README.md)
after loops. There is a difference between knowing an operator's name and having
the prerequisites to use it safely: pointer/class/allocation examples belong in
Phase2, not before a beginner knows what an object or pointer is.
