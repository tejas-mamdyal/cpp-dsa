# Independent practice

Try without the worked source. Unless specified otherwise, accept only the stated
domain. From unit04 onward, reject malformed/out-of-domain input with an error
message and exit1. Before unit04, document the valid-input assumption instead.
A slash in a sample below separates output lines; it is not a printed character.

## 1. Weeks and days

Read total days0..10000. Output full weeks and remaining days.

**Sample:** Input17 ->2 3

## 2. Minutes decomposition

Read minutes0..10000. Print hours and minutes remaining.

**Sample:** Input125 ->2 5

## 3. Four-mark average

Read four marks0..100. Print mean to two decimals.

**Sample:** Input1 2 3 4 ->2.50

## 4. Discount formula

Read price0..1000 and percent0..100 as doubles. Output discounted price to two decimals.

**Sample:** Input200 10 ->180.00

## 5. Tens digit

Read n0..100000. Output its tens digit; single-digit numbers have tens digit0.

**Sample:** Input472 ->7

## 6. Inside either interval

Read x in [-100,100]. Print1 when x is in[0,10] or[20,30], otherwise0.

**Sample:** Input15 ->0

## 7. Safe remainder predicate

Read a,b in [-100,100]. Print1 only if b is nonzero and a%b equals1.

**Sample:** Input7 3 ->1; input7 0 ->0

## 8. Grouping experiment

No input. Print24/6*2 and24/(6*2), then explain.

**Sample:** 8 / 2
