# Staged hints

Read only after writing a first attempt. Hints explain a method without providing
a copyable implementation. Check your code against the sample and your own edge cases.

## 1. Centered pyramid

<details><summary>Hint 1</summary>

Two loops have different jobs.

</details>

<details><summary>Hint 2</summary>

Print spaces first, then stars, then newline.

</details>

## 2. Checkerboard

<details><summary>Hint 1</summary>

Parity of row+column determines the cell.

</details>

<details><summary>Hint 2</summary>

Print(r+c)%2.

</details>

## 3. Unordered pairs

<details><summary>Hint 1</summary>

Avoid symmetric duplicates and self-pairs.

</details>

<details><summary>Hint 2</summary>

Start b at a+1.

</details>

## 4. Running totals

<details><summary>Hint 1</summary>

An accumulator survives across input iterations.

</details>

<details><summary>Hint 2</summary>

Update sum before printing it.

</details>

## 5. Range spread

<details><summary>Hint 1</summary>

Initialize both extremes from the first value.

</details>

<details><summary>Hint 2</summary>

Update min and max independently.

</details>

## 6. Count a target

<details><summary>Hint 1</summary>

Each input contributes0 or1 to the answer.

</details>

<details><summary>Hint 2</summary>

No array is needed for counting.

</details>

## 7. Row sums

<details><summary>Hint 1</summary>

Reset the sum at the start of each outer iteration.

</details>

<details><summary>Hint 2</summary>

Do not carry one row total into the next.

</details>

## 8. Prime count

<details><summary>Hint 1</summary>

Use an outer candidate loop and inner divisor loop.

</details>

<details><summary>Hint 2</summary>

Increment the count only after a candidate survives every divisor check.

</details>
