# Independent practice

Try without the worked source. Unless specified otherwise, accept only the stated
domain. From unit04 onward, reject malformed/out-of-domain input with an error
message and exit1. Before unit04, document the valid-input assumption instead.
A slash in a sample below separates output lines; it is not a printed character.

## 1. Centered pyramid

Read n0..10. Row r has n-r spaces and2*r-1 stars.

**Sample:** Input2 ->one space+* /***

## 2. Checkerboard

Read n1..10. Print n-by-n board of0 and1 starting0 in the top-left.

**Sample:** Input2 ->01 /10

## 3. Unordered pairs

Read n0..10. Print a b for every1<=a<b<=n.

**Sample:** Input3 ->1 2 /1 3 /2 3

## 4. Running totals

Read n0..100 and n values in[-100,100]. Print cumulative sum after each value.

**Sample:** Input3 2 -1 4 ->2 /1 /5

## 5. Range spread

Read n1..100 and n values in[-1000,1000]. Output maximum-minus-minimum.

**Sample:** Input3 -2 5 1 ->7

## 6. Count a target

Read n0..100, a target in[-100,100], then n values in that range. Output matches.

**Sample:** Input4 2 2 1 2 3 ->2

## 7. Row sums

Read rows,cols0..10 then rows*cols values in[-100,100]. Print one sum per row.

**Sample:** Input2 2 1 2 3 4 ->3 /7

## 8. Prime count

Read n0..1000. Output how many primes lie in2..n.

**Sample:** Input10 ->4
