# Decisions and input validation

Prerequisites: Units 01–03: values, expressions and bool.

Read [the unit notes](NOTES.md), then work through the lessons in order. The first
eight form the core route; later programs add reinforcement. Work through all of
them if a concept is still uncertain. Every source has a contract, explanation,
trace, cost, pitfalls and two follow-up tasks.

- [Choose between two outcomes](02_even_odd.cpp) — core
- [An else-if chain classifies values](03_sign.cpp) — core
- [Compare two candidates](04_maximum_two.cpp) — core
- [Maintain the best candidate](05_maximum_three.cpp) — core
- [Order overlapping thresholds](06_grade.cpp) — core
- [Combine exceptions in a rule](07_leap_year.cpp) — core
- [Validate a geometric condition](08_triangle.cpp) — core
- [Discrete choices with switch](09_days_in_month.cpp) — reinforcement
- [Handle an operation-specific failure](10_safe_division.cpp) — reinforcement
- [Nested decisions and a threshold](11_shipping.cpp) — reinforcement
- [Charge only the excess at the next rate](12_progressive_bill.cpp) — reinforcement
- [Character comparisons and logical ranges](13_character_category.cpp) — reinforcement

Attempt [independent practice](PRACTICE.md) before opening [hints](HINTS.md).
Finish [the checkpoint](CHECKPOINT.md) before advancing. Revisit a weak concept
with a smaller input rather than memorizing a complete solution.
