# Debugging, edge cases and testing habits

Prerequisites: Units 01–07; functions and input validation.

Read [the unit notes](NOTES.md), then work through the lessons in order. The first
eight form the core route; later programs add reinforcement. Work through all of
them if a concept is still uncertain. Every source has a contract, explanation,
trace, cost, pitfalls and two follow-up tasks.

- [Repair the accumulator identity](02_empty_product.cpp) — core
- [Avoid an imaginary candidate](03_negative_max.cpp) — core
- [Convert before division](04_lost_fraction.cpp) — core
- [Widen before multiplication](05_overflow_before_assignment.cpp) — core
- [Handle a zero-iteration edge case](06_zero_digit.cpp) — core
- [Use a comparison in a condition](07_comparison_not_assignment.cpp) — core
- [Prevent accidental fallthrough](08_switch_break.cpp) — core
- [Restore progress toward termination](09_progress_update.cpp) — reinforcement
- [A for loop still updates after continue](10_continue_update.cpp) — reinforcement
- [Independent updates need independent conditions](11_separate_checks.cpp) — reinforcement
- [Malformed input must not become a calculation](12_reject_bad_stream.cpp) — reinforcement
- [Check a formula against an independent baseline](13_assertions_and_oracle.cpp) — reinforcement

Attempt [independent practice](PRACTICE.md) before opening [hints](HINTS.md).
Finish [the checkpoint](CHECKPOINT.md) before advancing. Revisit a weak concept
with a smaller input rather than memorizing a complete solution.
