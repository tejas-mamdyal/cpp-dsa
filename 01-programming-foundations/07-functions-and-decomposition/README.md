# Functions, parameters and decomposition

Prerequisites: Units 01–06: decisions, loops and repeated input.

Read [the unit notes](NOTES.md), then work through the lessons in order. The first
eight form the core route; later programs add reinforcement. Work through all of
them if a concept is still uncertain. Every source has a contract, explanation,
trace, cost, pitfalls and two follow-up tasks.

- [Return a computed value](01_square.cpp) — core
- [Arguments bind to parameters in order](02_two_parameters.cpp) — core
- [A function can answer a yes/no question](03_predicate.cpp) — core
- [Passing by value does not update the caller](04_value_copy.cpp) — core
- [A procedure performs an action](05_void_procedure.cpp) — core
- [Reject a candidate early](06_early_return.cpp) — core
- [Compose functions with clear responsibilities](07_composition.cpp) — core
- [Declare a function before its use](08_prototype.cpp) — core
- [Local state is fresh on each call](09_local_lifetime.cpp) — reinforcement
- [Overload by parameter list](10_overload.cpp) — reinforcement
- [Encapsulate a state-changing loop](11_gcd.cpp) — reinforcement
- [Document a helper precondition](12_integer_power.cpp) — reinforcement
- [Build a task from smaller named steps](13_decompose_palindrome.cpp) — reinforcement

Attempt [independent practice](PRACTICE.md) before opening [hints](HINTS.md).

with a smaller input rather than memorizing a complete solution.
