# Standard scalar practice

Solve from a blank file; state constraints and add a boundary test.

## 1. Coprime test

Decide whether two positive integers are coprime.

Expected example: 14,25 ->true.

## 2. LCM zero

Define lcm when either operand is zero and avoid dividing by zero.

Expected example: 0,0 ->0.

## 3. Digit power count

Check an Armstrong candidate with a different number of digits.

Expected example: 9474 ->true.

## 4. Perfect boundary

Check1,6,28 and12.

Expected example: false,true,true,false.

## 5. Factorial digit zero

Explain why0 is not a digit-factorial number.

Expected example: 0! gives1, not0.

## 6. Fibonacci index

Return F(n) for0<=n<=92 without computing F(93).

Expected example: F(0)=0,F(10)=55.

## 7. Automorphic number

For n<=100000, test whether n squared ends in the digits of n.

Expected example: 76 ->true because5776 ends76.

## 8. Prime range

Print primes in a small inclusive range.

Expected example: 10..20 ->11,13,17,19.
