# Standard scalar problems

These are reinforcement after the function/gcd lessons. Existing prime, factorial,
digit reversal, palindrome and Fibonacci input lessons remain in the loops unit;
these helpers add related variations and explicit boundary reasoning.

1. [LCM](01_lcm.cpp): divide by gcd before multiplication and define the zero case.
2. [Fibonacci trace](02_fibonacci.cpp): contrast fixed demonstrations with the earlier
   input-driven sequence; two live state variables replace storing the sequence.
3. [Armstrong](03_armstrong.cpp): count digits, use integer powers, include zero.
4. [Perfect and strong numbers](04_perfect_and_strong.cpp): distinguish proper-divisor
   sums from digit-factorial sums; remember that0! is1.
