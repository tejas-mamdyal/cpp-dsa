# Independent practice

Try without the worked source. Unless specified otherwise, accept only the stated
domain. From unit04 onward, reject malformed/out-of-domain input with an error
message and exit1. Before unit04, document the valid-input assumption instead.
A slash in a sample below separates output lines; it is not a printed character.

## 1. Study card

No input. Print your chosen name, branch and study goal on three lines.

**Sample:** For name Asha, branch CSE, goal Practice: Asha / CSE / Practice.

## 2. Expression label

No input. Print the literal expression 8 * 7 and its calculated answer on the next line.

**Sample:** 8 * 7 / 56

## 3. Echo pair

Read two whole numbers in [-100,100]. Print them in reverse input order.

**Sample:** Input 4 9 -> 9 4

## 4. Difference

Read two integers in [-100,100]. Print first minus second.

**Sample:** Input 3 8 -> -5

## 5. Square perimeter

Read side length0..1000. Output perimeter.

**Sample:** Input 6 -> 24

## 6. Ticket total

Read price0..100 and count0..100. Output total price.

**Sample:** Input 15 4 ->60

## 7. Three-value rotation

Read a,b,c in [-100,100]. Output the result of rotating values so a gets old c, b gets old a, c gets old b.

**Sample:** Input 1 2 3 ->3 1 2

## 8. Trace assignment

Without running first, predict output of a=2; b=a+3; a=b*2; then print a,b. Create a program to verify.

**Sample:** Expected 10 5
