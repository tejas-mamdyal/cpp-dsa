# First instructions and input/output

Prerequisites: None; read 00-start-here first.

Read [the unit notes](NOTES.md), then work through the lessons in order. The first
eight form the core route; later programs add reinforcement. Work through all of
them if a concept is still uncertain. Every source has a contract, explanation,
trace, cost, pitfalls and two follow-up tasks.

- [Your first instruction](01_hello.cpp) — core
- [Separate output lines](02_two_lines.cpp) — core
- [Representing special characters](03_escape_sequences.cpp) — core
- [Comments explain intent](04_comments.cpp) — core
- [Text versus calculation](05_literal_expressions.cpp) — core
- [A variable remembers a value](06_named_storage.cpp) — core
- [Instructions update state](07_assignment_order.cpp) — core
- [Read a whole number](08_read_one_integer.cpp) — core
- [Read and combine two values](09_read_two_integers.cpp) — reinforcement
- [Translate a formula into steps](10_rectangle_area.cpp) — reinforcement
- [Preserve a value before overwriting it](11_swap_storage.cpp) — reinforcement
- [A complete input-process-output algorithm](12_dry_run_bill.cpp) — reinforcement

Attempt [independent practice](PRACTICE.md) before opening [hints](HINTS.md).
Finish [the checkpoint](CHECKPOINT.md) before advancing. Revisit a weak concept
with a smaller input rather than memorizing a complete solution.
