# Phase 1: programming from absolute zero

A complete first programming course: **122 worked programs, 92 independent practice

problems, eight original checkpoints plus operator/application checkpoints and three additional projects**. Use C++17.

All lessons run independently; never link every main function into one executable.

## Start and reading order

Begin with [the setup and first-session guide](../00-start-here/README.md).

No arrays, STL containers, pointers or recursion are required for this phase. The

operator catalogue previews advanced names but defers their implementations until

their Phase2/later prerequisites. Read the four XOR/bit applications after loops.

The supported toolchain uses int with at least32 bits and long long with at least64;

the supplied input bounds are chosen for these ranges. The types unit explains

why exact storage sizes should not be guessed on an unfamiliar platform.
