# Staged hints

Read only after writing a first attempt. Hints explain a method without providing
a copyable implementation. Check your code against the sample and your own edge cases.

## 1. Sum of evens

<details><summary>Hint 1</summary>

Filter loop values or advance by2.

</details>

<details><summary>Hint 2</summary>

Initialize sum0; include n when even.

</details>

## 2. Digit frequency

<details><summary>Hint 1</summary>

Extract each digit exactly once.

</details>

<details><summary>Hint 2</summary>

Use do/while and compare n%10 to target.

</details>

## 3. Largest digit

<details><summary>Hint 1</summary>

Maintain the best digit seen.

</details>

<details><summary>Hint 2</summary>

Start at0 because digits are nonnegative.

</details>

## 4. Integer power

<details><summary>Hint 1</summary>

The empty product is1.

</details>

<details><summary>Hint 2</summary>

Multiply by the base exponent times.

</details>

## 5. Arithmetic sequence

<details><summary>Hint 1</summary>

A count-based rule works even when difference is zero or negative.

</details>

<details><summary>Hint 2</summary>

Print term then add difference.

</details>

## 6. Geometric sequence

<details><summary>Hint 1</summary>

Use a count, not an increasing-value termination condition.

</details>

<details><summary>Hint 2</summary>

Update term*=ratio after each output.

</details>

## 7. Sentinel average

<details><summary>Hint 1</summary>

Track both sum and count.

</details>

<details><summary>Hint 2</summary>

Check count before division; sentinel is not data.

</details>

## 8. Menu repetition

<details><summary>Hint 1</summary>

A quit command terminates without entering an operation.

</details>

<details><summary>Hint 2</summary>

Use a loop with validated command dispatch.

</details>
