Complete without looking at worked solutions. Use Sum of evens as the implementation
task and Menu repetition as the transfer task from PRACTICE.md.

1. Explain the main concept from NOTES.md in your own words. (2 points)
2. Hand-trace a core example and predict its exact output. (2 points)
3. Implement the first practice problem independently. (4 points)
4. Test a typical case and the smallest permitted case; explain the results. (3 points)
5. Implement or reason through the transfer task, explaining each decision. (4 points)
6. Identify a plausible mistake, demonstrate a failing case and repair it. (3 points)
7. Explain time and extra space using the number of executed operations. (2 points)

Target: 16/20, including at least 3/4 for independent implementation. Revisit the
corresponding lesson when a question cannot be explained. Before unit04, test only
the stated valid domain; later, include rejected malformed input too.

Record: date, score, a misconception, its counterexample, and when you will retry.
Passing once is a checkpoint; retention means you can repeat the task later.
