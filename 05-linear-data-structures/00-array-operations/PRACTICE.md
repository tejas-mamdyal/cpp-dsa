# Independent practice

Use small stated bounds,n<=1000 unless the problem requires a smaller bound.
Explain preconditions,errors,correctness,time and owned/auxiliary memory. Reclaim
node allocations and never dereference erased observers.

## 1. Task

Adapt signed right rotation to a left-rotation API.

Example/result: [1,2,3],left1 ->[2,3,1].

## 2. Task

Remove negatives stably in place.

Example/result: [-1,3,0,-2] ->[3,0].

## 3. Task

Reject insertion into a full active-prefix array.

Example/result: capacity5,size5 unchanged.

## 4. Task

Merge repeated keys into provided trailing live slots.

Example/result: [1,2] plus[2,2] ->[1,2,2,2].

## 5. Task

Show a candidate without a true majority.

Example/result: [1,2,3] has none.

## 6. Task

Reshape2x3 to1x6 and reject4x2.

Example/result: same6 row-major cells.

## 7. Task

Explain immediate-zeroing cascades.

Example/result: one original zero must not mark unrelated rows.

## 8. Task

Specify repeated-space handling before extending word reversal.

Example/result: normalize or preserve exactly.
