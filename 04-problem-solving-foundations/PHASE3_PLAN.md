## Ordering and acceptance

Complexity derives counts/models/space before recursion. Recursion teaches base,
progress,frames and return flow before merge/quicksort. Search distinguishes exact
matches and boundaries. Heap sort introduces the array heap invariant locally.
Hash collision/equality/load concepts precede identity-set applications. Linked
fundamentals establish owners/observers and cleanup before mutations,cycles and
shared tails. Stacks precede FIFO/LIFO compositions.

The toolkit integrates a vector sequence,uniquely owned list,actual bounded stack
and ring queue. It validates complete commands before mutation and supplies mixed
reference-model checks,capacity tests and live-node accounting. Students complete
unit checkpoints,the40-point project rubric and80-point final assessment before
Phase4. Repository delivery does not automatically imply personal mastery.

## Scope boundary

Phase4 develops windows,prefix/difference arrays,monotonic stacks/deques,binary
search on answers and greedy/interval patterns. Later phases develop advanced
backtracking,trees,graphs,DP and engineering. Those are scheduled separately.

used when inventory or reading order changes.
