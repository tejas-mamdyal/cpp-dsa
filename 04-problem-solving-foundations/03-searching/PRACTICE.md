# Independent practice

Use small stated bounds,n<=1000 unless the problem requires a smaller bound.
Explain preconditions,errors,correctness,time and owned/auxiliary memory. Reclaim
node allocations and never dereference erased observers.

## 1. Task

Return the last duplicate using a boundary,not a suffix scan.

Example/result: [1,2,2,4],2 ->index2.

## 2. Task

Insert before all equal keys in sorted input.

Example/result: [1,2,2],2 ->index1.

## 3. Task

Count values strictly between low and high.

Example/result: [1,2,2,3,4],1..4 ->3.

## 4. Task

Trace all-false and all-true predicates.

Example/result: n8 ->boundaries8 and0.

## 5. Task

Return ceiling square root under the documented64-bit bound.

Example/result: 26 ->6;25 ->5.

## 6. Task

Give a row/column sorted matrix that is not row-major sorted.

Example/result: [1,4;2,5].

## 7. Task

Implement recursive first>=key with no copied vector.

Example/result: [1,3,3],3 ->1.

## 8. Task

Compare chosen comparison counts for linear and binary search.

Example/result: absent key in31 values.
