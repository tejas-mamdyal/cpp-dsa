# Independent practice

Use small stated bounds,n<=1000 unless the problem requires a smaller bound.
Explain preconditions,errors,correctness,time and owned/auxiliary memory. Reclaim
node allocations and never dereference erased observers.

## 1. Task

Compute parity of the set-bit count.

Example/result: 7 odd;3 even.

## 2. Task

Define highest-bit position for zero and powers of two.

Example/result: zero absent;16 index4.

## 3. Task

Explain a broken singleton multiplicity precondition.

Example/result: triples are outside the paired contract.

## 4. Task

Check Hamming symmetry and self-distance.

Example/result: distance10,12 is2.

## 5. Task

List all submasks of5.

Example/result: 5,4,1,0.

## 6. Task

Count stored integers across all n-position subsets.

Example/result: n*2^(n-1) for n>0.

## 7. Task

Compute XOR0..9 and3..6 safely.

Example/result: 1 and4.

## 8. Task

Explain why shifting1U by its width is invalid.

Example/result: count must be smaller than width.
